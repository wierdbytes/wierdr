# iPhone: установка, подключение, экран

## Экран не гаснет

**Решение:** Пока на экране работающий (`working`) агент

**Почему / цена:** Заблокированный iPhone рвёт соединение; цена — батарея, пока смотришь, как агент
работает.

## Установка по воздуху

**Решение:** `scripts/ota.sh`: страница + manifest + ipa по HTTPS на имени Mac в tailnet
(`tailscale serve`, путь `/wierdr`), раздаёт локальный `python3 http.server` (127.0.0.1:8791)

**Почему / цена:** Tailscale.app не умеет раздавать папки (sandbox), поэтому нужен процесс‑сервер.
Только tailnet, без Funnel; остальные обработчики `tailscale serve` не трогаются. Выключить:
`scripts/ota.sh off`. Сборка development: ставится только на устройства из профиля команды (iPhone
13 Pro Max в нём есть, профиль до 23.07.2027).

## Автоподключение

**Решение:** На iPad и iPhone при запуске — к последнему хосту, пока ты сам не нажал Disconnect

**Почему / цена:** Открыл приложение — видишь агентов, без лишнего тапа. Сначала было только на
iPhone (на iPad думали, что привычнее экран хостов); по просьбе включено и на iPad. **Цена:** чтобы
попасть на экран хостов, нужен Disconnect; хост с паролем спрашивает его сразу при запуске.

## Установка и управление по tailnet

**Решение:** Установка — откуда угодно: OTA‑страница по HTTPS на tailnet‑имени Mac (проверено с
iPhone вне дома, сборка 0.2.0 (3) встала), нажатием на самом iPhone. Без нажатия
(`scripts/iphone.sh install` через devicectl) и управление через WDA — только когда iPhone дома
(USB/та же Wi‑Fi)

**Почему / цена:** Xcode/devicectl находят устройство по Bonjour (`_remotepairing._tcp`), а он не
ходит через Tailscale; WDA держится сессией `xcodebuild` и умирает, когда iPhone уходит из сети
(проверено). Неофициальный мост (переопубликовать Bonjour‑записи iPhone на Mac + TCP/UDP‑релей, как
`iphone-tailnet-bridge`) дал бы devicectl и WDA издалека, но только когда iPhone на какой‑нибудь
Wi‑Fi: на сотовой сети слушатель беспроводной отладки (порт 49152) выключен — так было и сейчас.
Мост не ставили (решение от 11.11). Пока Wierdr на экране, OTA‑обновление, похоже, откладывается
(две попытки из WDA с открытым Wierdr ограничились HEAD), с экрана «Домой»/из Safari — проходит.

## Узкое окно iPad

**Решение:** Тоже раскладка iPhone (вместо сложенного `NavigationSplitView`); клавиши — свайпом
влево по терминалу, ⏎ — на высоте свайпа, как в широком

**Почему / цена:** Раньше там был системный стек «сайдбар → панель», не вылизанный; теперь одна
логика на все узкие экраны. Шрифт/отступы/щипок — по устройству (на iPad остаются свои). Узкое окно
у правого края экрана иначе спорило бы со Slide Over.
