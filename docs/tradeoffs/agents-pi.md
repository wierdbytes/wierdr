# Компромиссы: pi

## pi: данные агента и сабагенты

**Решение:** Метки `agent.*`, лимиты, bash в терминалах herdr-core и сабагенты pi — одно расширение
из этого репозитория, `@wierdbytes/pi-wierdr` (`Integrations/pi`, [pi.md](../pi.md)), вместо
`@wierdbytes/pi-herdr` и `@wierdbytes/pi-agents` из pi-wierd-stuff. В npm его выпускает CI этого
репозитория через Trusted Publishing (OIDC). Имена, которые видят другие программы (метки
`pi-agents.*` и `pi-herdr.bash`, `PI_AGENTS_*`, RPC `agents:rpc:*`), остались прежними

**Почему / цена:** Метки и `limits` читает в первую очередь Wierdr, и те же пишут плагины `cc` и
`codex` отсюда же: смена формата — один коммит. Пакеты ставились только вместе и оба работают только
в herdr-core. Старые имена — чтобы pi, обновлённый на ходу, находил своих сабагентов, а pi-web и
pi-voice продолжали чистить окружение своих `pi -p`. **Цена:** репозиторий приватный — у публичного
пакета нет provenance и открытого исходника (ссылки с npm ведут в закрытый репозиторий); Actions
тратит минуты приватного репозитория (только на push с изменениями в `Integrations/pi`).
