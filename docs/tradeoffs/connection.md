# Компромиссы: SSH и вход

## SSH

**Решение:** Только Ed25519/ECDSA‑P256 ключи и пароль

**Почему / цена:** SwiftNIO SSH не поддерживает RSA‑ключи пользователя, keyboard‑interactive,
ssh‑agent, ProxyJump. Для Mac это не мешает (ключ генерируется на iPad).

## Пароль

**Решение:** Не хранится нигде: спрашивается при каждом подключении (Connect, Retry, возврат к
последнему хосту при запуске), в памяти — только у живой сессии для её переподключений. После
каждого входа по паролю лист «Set Up <хост>» предлагает ключ устройства (Sign In)

**Почему / цена:** Пароль от Mac — пароль учётной записи, хранить его на телефоне незачем, когда
есть ключ: один ввод — и после кнопки вход по ключу. Цена: пароль вводится при каждом подключении,
пока ключ не поставлен; после выгрузки приложения iOS тоже. Автозаполнение паролей iOS
(`textContentType(.password)`) остаётся выбором человека. Сборки до 89 хранили пароли в связке
ключей: они удаляются при запуске.

## Known hosts

**Решение:** Своё хранилище TOFU (JSON в Application Support), не `~/.ssh/known_hosts`

**Почему / цена:** На iOS нет общего known_hosts.
