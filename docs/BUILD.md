# Building and installing Wierdr

Requirements: Xcode 27 (the project is generated by XcodeGen, already committed
as `Wierdr.xcodeproj`), Apple Development certificate of team `AUL4CCB2XY`,
the iPad registered in that team (the iPad Pro 13" M4,
UDID `<UDID>`, already is).

## Install on the iPad (first time)

1. Connect the iPad to the Mac with a USB‑C cable, unlock it, tap **Trust**.
2. On the iPad: **Settings › Privacy & Security › Developer Mode** → on
   (the iPad restarts; confirm after reboot). Only needed once.
3. On the Mac:
   ```sh
   cd ~/me/dev/wierdr
   make install          # builds a signed Debug build and installs it with devicectl
   ```
   or open `Wierdr.xcodeproj` in Xcode, pick the iPad as destination and press Run.
   Xcode asks once to trust the SwiftTerm build plugin ("Trust & Enable").
4. If iOS says the developer is not trusted: **Settings › General › VPN & Device
   Management › Apple Development: … › Trust**.

After the first cable install you can enable **Connect via network** for the
iPad in Xcode › Window › Devices and Simulators, and later installs work over
Wi‑Fi (`make install` too).

A prebuilt development‑signed `dist/Wierdr.ipa` can also be installed with
Apple Configurator, Xcode's Devices window (drag the .ipa onto the device) or
`xcrun devicectl device install app --device <udid> dist/Wierdr.ipa`.

## Prepare the Mac (the machine Wierdr connects to)

1. **System Settings › General › Sharing › Remote Login** → on (already on
   for this Mac). Allow your user.
2. herdr-core must be installed (`~/.local/bin/hc`; it comes with the Herdr app).
3. In Wierdr: add a host — address `mentoair.local` (same Wi‑Fi),
   `192.168.x.y`, or over Tailscale `mentoair-1` / `100.x.y.z`; user
   `mentor`. Choose **Password** for the first connection, or copy Wierdr's
   public key (shown in the host editor) into `~/.ssh/authorized_keys` on the
   Mac. After a password login Wierdr offers to install its key for you.

## Other targets

```sh
make test     # unit tests of WierdrKit on macOS
make sim      # iPad Pro 13" (M4) simulator
make ipa      # dist/Wierdr.ipa (development signing)
```

`scripts/test-sshd.sh start` runs a throwaway sshd on `127.0.0.1:2222` for
testing the simulator build against the local core without touching
`~/.ssh/authorized_keys`.
