# Лендинг

Сайт Wierdr для пользователей — `https://wierdr.workat.dev`, исходники в `Site/`. Одна
страница на английском: зацепить и заинтересовать, без подробностей и оговорок (их место —
README и docs). Призыв: «Coming soon to the App Store» (не ссылка) и «View on GitHub».
Решено 2026‑11‑20: без waitlist и бэкенда; когда приложение выйдет, плашку заменить на
бейдж App Store со ссылкой.

## Устройство

- **Хостинг.** Cloudflare Workers со статикой (`assets`, без скрипта), тот же аккаунт, что
  у релея. Только свой домен (`routes` с `custom_domain`: wrangler сам заводит DNS и
  сертификат), `workers.dev` и preview URL выключены. Pages не нужен: Cloudflare ведёт
  статику на Workers.
- **Файлы** (`Site/public`): `index.html`, `styles.css`, `main.js` (появление секций при
  прокрутке и рамка у шапки), `404.html`, `_headers`, `robots.txt`, `sitemap.xml`,
  `favicon.svg` (иконка из `docs/app-icon.svg` со скруглением), `favicon-32.png` и
  `favicon.ico` (Safari до 26 не берёт SVG), `apple-touch-icon.png`, `og.jpg` (карточка для
  соцсетей, 1200×630), `img/*.webp`. Без сборки, без внешних шрифтов и скриптов: шрифт
  системный (SF на устройствах Apple).
- **Появление секций.** `main.js` с `defer`; то, что уже на экране (или выше), когда он
  выполнился, остаётся как есть, а секции ниже прячет он сам (класс `js` на `<html>`) и
  показывает по прокрутке. Пока файл не выполнился — медленно или вовсе не загрузился, —
  ничего не скрыто. Фокус с клавиатуры внутри секции показывает её сразу. Первый экран
  (заголовок, текст, кнопки) не прячется никогда, телефон в нём появляется анимацией CSS.
- **Вид.** Тёмная тема по цветам приложения (Atom One Dark) и слоновая кость иконки; цвета
  статусов — как в приложении (красный — needs you, зелёный — done, жёлтый — working).
  Рамки устройств нарисованы CSS вокруг скриншотов (размеры в `cqw`, контейнер — ширина
  устройства), у всех телефонов Dynamic Island. В hero он один раз раскрывается в «Needs you»
  и остаётся открытым (`clip-path`, без перекладки); плашки статусов появляются один раз;
  бесконечных анимаций нет. `prefers-reduced-motion` сразу показывает конечное состояние.
- **Призыв.** Плашка «Coming soon to the App Store» — чёрная, как бейдж Apple, но не кнопка;
  кнопка — «View on GitHub». На телефоне hero в одну колонку, телефон раньше строки логотипов,
  чтобы он был на первом экране; iPad крупнее экрана и листается вбок, чтобы его можно было
  прочесть.
- **Заголовки** (`_headers`): CSP только `'self'`: ни встроенных скриптов, ни атрибутов
  `style` (свойства через `el.style` из `main.js` можно). Картинки, иконки и `og.jpg`
  кешируются на сутки: заменяя картинку заметно, лучше дать файлу новое имя.

## Картинки

Скриншоты — демо приложения в симуляторах, тёмная тема, статус‑бар 9:41
([BUILD.md](BUILD.md#проверка-в-симуляторе-iphone), `scripts/iphone-sim.sh`). Полноразмерные
лежат в `Site/shots/` (не в git): `iphone-list.png` (список у пространства wierdr, hero),
`iphone-banner.png` (баннер Done над терминалом, задний телефон hero), `iphone-hosts.png`
(верх списка с двумя машинами), `iphone-pane.png` (запрос разрешения и панель клавиш),
`iphone-lock.png` (Live Activity: `docs/screenshots/iphone-live-activity.jpg` без «Carrier»
симулятора, `og/uncarrier.mjs`), `ipad.png` (iPad в ландшафте). Каждая картинка на странице
одна: повторы ревьюеры заметили. `sh Site/images.sh` делает из них WebP (`cwebp`) и иконки.

`og.jpg`, `favicon-32.png`, `favicon.ico`: `bunx wrangler dev --port 8788` в `Site/`, затем
`node og/render.mjs` (Playwright: `bun install` в `Site/`, браузер — `npx playwright install
chromium`). Разметка карточки — `og/og.html`.

## Развёртывание

```sh
cd Site
bun install
bunx wrangler dev --port 8788   # локально, с теми же заголовками
bunx wrangler deploy            # wierdr.workat.dev
```

Проверка после выкладки: страница в Chromium и WebKit на 1440, 1180, 820 и 390 px
(Playwright, по экрану за раз), консоль без ошибок, нет горизонтальной прокрутки. В WebKit
`page.screenshot()` Playwright вставляет свой стиль, и CSP его отвергает: это сообщение от
инструмента, не от страницы.

## Ревью

После первой выкладки страницу смотрели два ревьюера (Opus и GPT‑6.2 Sol), правки приняты:
страница не пустеет без `main.js`, логотип ведёт наверх (`#top` не на липкой шапке), Dynamic
Island читается целиком и не крутится бесконечно (анимации не дольше 5 с), контраст серого
текста ≥ 4.5:1, Herdr назван в первом экране, плашка App Store не похожа на кнопку, тексты о
приватности и установке точны (терминалы — напрямую по SSH, шифруются имена агентов в Live
Activity, она только на iPhone, Remote Login).

## Ловушки

- Сразу после первого деплоя системный резолвер Mac может помнить NXDOMAIN для нового
  поддомена (мы спросили его до выкладки): `curl --resolve` или Chromium с
  `--host-resolver-rules`, WebKit — через прокси.
- `.phone { width }` после `.phone-front { width }` с той же специфичностью перебивал
  размер телефонов в hero: ширину задаёт только конкретный класс.
- Ореолы за телефонами шире колонки: `main { overflow-x: clip }`, иначе на телефоне
  страница едет вбок.
